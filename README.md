# Bảng ra Excel

App trên máy: đọc PDF scan và ảnh chụp bảng (hóa đơn, bảng lương, sao kê, giấy tờ) rồi xuất Excel. Có tiếng Việt có dấu. File không gửi lên mạng.

## Mở app

Double-click `CHAY.bat`, hoặc shortcut **Bảng ra Excel** trên Desktop.

Cần Python 3.11 trở lên. Lần đầu:

```
pip install -r requirements.txt
```

Lần đầu mở app sẽ tải bộ đọc chữ tiếng Việt (vài phút). Các lần sau mở ngay.
